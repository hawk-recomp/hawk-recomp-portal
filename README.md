# HAWK Recomp

**Bringing classic console games to modern PCs.**

HAWK Recomp is an open-source community initiative focused on native game recompilation, game preservation, and making classic console gaming more accessible on modern hardware.

## Our Mission

We aim to support the development of native PC ports through collaboration, research, documentation, and open-source tooling.

Our goals include:

- Contributing to existing game recompilation projects.
- Researching native recompilation techniques.
- Building accessible tools and documentation.
- Tracking game compatibility and development progress.
- Creating a community portal for developers and players.

## First Research Project — FIFA Street 2

Our initial research focuses on **FIFA Street 2 (Original Xbox)**.

We plan to investigate existing recompilation efforts, reproduce technical issues, document findings, and contribute improvements where permitted.

This is an experimental research initiative. A playable native PC version is not currently guaranteed.
